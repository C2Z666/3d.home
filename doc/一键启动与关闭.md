# 一键启动与关闭

在 /home/robot/zhangzhang/3d.home 下执行：

```bash
# 仅预览将关闭的本项目进程
python3 stop.py --dry-run
# 关闭本项目服务
python3 stop.py
# 稍后重新启动
bash scripts/start.sh
```

关闭顺序：停止启动/切图工作进程，尝试取消网页导航，关闭网页入口及导航监督器、Nav2、预览规划、扫描、定位和FAST-LIO；留出bridge看门狗和减速时间，再退出bridge。按真实命令行和进程组识别本项目，不按过期PID文件直接杀进程。不关闭原厂传感器、SSH、远程连接或其他项目。

日志 work/stop.log。失败返回非零并打印 STOP_FAILED；完成打印 STOPPED。无ROS环境依赖，不发送运动/姿态请求。进程退出不等于实体机身停稳测量。
